# 歴史鉄道 現在仕様・QA整理

## 目的
授業内約10分で完結する、教員1名＋生徒最大5名のリアルタイム教育用すごろく。

## 固定仕様
- 参加コード: 186800
- 教科範囲: 公共
- 表現: 中学生でも意味を理解できる言葉を優先
- 難易度: 標準よりやや難しい
- 5ターン制
- 全員同時進行
- 最終問題: 全員参加の早押し
- 勝敗: 所持金 + 物件価値 + ボーナス

## 教員の流れ
1. トップ画面で「すぐゲームを作る」
2. 固定部屋 186800 を初期化
3. 生徒参加を待つ
4. ゲーム開始
5. 90秒×5ターン
6. 60秒の最終早押し
7. 結果発表

## 生徒の流れ
1. 「参加する」
2. 固定コード186800で入室
3. 入室順に色と番号を自動割当
4. 各ターンでサイコロを1回振る
5. 分岐ルートを選ぶ
6. 止まった駅のマス効果を処理
7. 最終早押し
8. 個人成績確認

### プレイヤー割当
- 1人目: 赤1
- 2人目: 青2
- 3人目: 緑3
- 4人目: 黄4
- 5人目: 黒5
- 名前入力なし

## すごろく要素
20駅の周回型ルート。
各駅は固定のマス種別を持つ。

- 🚉 出発
- 💰 利益
- 💸 損失
- ❓ 公共クイズ
- ⚖️ 決断
- 🏯 物件

生徒画面には現在地、目的地、目的地までの残りマス、ミニ盤面を表示。
教員画面には全20駅、各マス種別、参加人数、目的地、列車位置を表示。

## 目的地
- 初期目的地を設定
- 目的地にぴったり止まると +5,000円
- 教員画面に到着演出
- 到着後は次の目的地へ変更

## 疫病神
- 各ターン終了時に最下位へ付与
- サイコロ -1
- そのターンで -1,000円
- クイズ正解で解除
- 疫病神中のクイズ正解賞金は2倍

## 最終早押し
- 正解: +10,000円
- 正解者の回答時刻はFirebaseサーバー時刻で記録
- 速度1位: +30,000円
- 速度2位: +20,000円
- 速度3位: +10,000円
- 速度ボーナスは教員側で最終確定時に付与

## 表彰
- 総合優勝
- クイズ王
- 大地主
- 豪運王
- 波乱王

## 今回修正した不具合
1. Firebase同期直後にクイズ・物件画面が消える問題
   - pendingEvent をDBに保存し、再描画してもイベントを維持する方式へ変更

2. 損失マスで「確定」を押さずにターン終了すると損失を回避できる問題
   - ターン終了時に未処理イベントを自動解決

3. 教員画面を再読み込みするとホスト画面へ戻れない問題
   - sessionStorageのhostKeyから復帰

4. 生徒画面を再読み込みすると再入室になりやすい問題
   - localStorageのplayerIdから復帰

5. 最終早押しが端末時刻基準だった問題
   - Firebaseサーバー時刻へ変更

6. 最終速度ボーナスを生徒端末側で計算していた問題
   - 教員側の最終確定処理へ移動

7. クイズの正解位置が1番目に偏っていた問題
   - 正解位置を分散

8. ランダム参加コードで授業ごとにコードが変わる問題
   - 186800固定へ変更

## 残る重要課題
### 1. サイコロ判定が生徒ブラウザ側
現在はMath.random()で生徒端末側が出目を作る。
通常授業では動作するが、開発者ツールを使えば改変できる。
本番強化時はCloud Functions側で出目を確定する。

### 2. Firebase Databaseの書き込み権限
現状は試作用として広め。
実運用では教員・生徒ごとの書き込み先を制限する必要がある。

### 3. 固定コードの同時利用
186800固定のため、複数教室が同時に使うと同じ部屋になる。
現状は1教室での利用を前提とする。

### 4. 5台実機確認
設計上は5名対応。5台の実端末で同時操作の最終確認は必要。
