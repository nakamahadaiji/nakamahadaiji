# LIFE Lv.

現実の行動を経験値に変える、スマホ向け人生RPGです。

## 初版の機能

- プレイヤーレベル / EXP
- 毎日のクエスト4件
- クエスト達成による経験値・ステータス成長
- 仕事 / お金 / 知識 / 健康 / 家族 / 趣味の6ステータス
- 連続達成日数
- 実績解除
- プレイヤー名・クラス設定
- ブラウザ内データ保存
- PWA対応
- オフライン対応
- iPhoneを中心にしたモバイルUI

## 使い方

`life-lv/index.html` をWebサーバーで開いてください。GitHub Pagesで公開すれば、そのままスマートフォンから利用できます。

## 設計方針

単なる習慣管理ではなく、「現実の自分を育成するゲーム」に見えることを優先しています。クエストを終えるたびに数値が積み上がり、自分の人生の偏りや成長が視覚化されます。

## 今後の拡張候補

- 独自クエスト作成
- 週間 / 月間レポート
- 称号・職業ごとの能力差
- クラウド同期
- フレンド・パーティー機能
- AIによるクエスト生成
