# 株式売買ゲーム

政治・経済の授業用に作成した、短期売買に特化した株式売買ゲームです。ニックネーム入力はありません。

## 練習用
- 架空企業5社
- 3分または5分
- 株価が毎秒ランダムに変動
- 短期の勝敗が偶然に大きく左右されることを体験するモード

## 本番用
- 実在する東京証券取引所上場企業130社以上
- 3分または5分
- 2024年8月5日の急落局面を題材にした再現モード
- 実際の日足データの始値・高値・安値・終値を取得し、その範囲をもとに授業用の1秒チャートを作成
- 途中の秒ごとの動きは実際の分足データではなく、授業用に再構成したもの

## 注意
- 教育用ゲームです。実際の投資判断を目的とするものではありません。
- 本番用はブラウザから過去株価データを取得します。学校のネットワーク設定などで取得できない場合は、練習用を使用してください。
